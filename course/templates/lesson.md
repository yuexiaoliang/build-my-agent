# 当前小步备课模板

供导师按需填写，学习者无需填表。只准备当前小步；已有材料可复用，不为了模板补造图、指标或实验。

## 定位与已有能力

单元 ID / domains / 当前整体任务 / 这一步在运行链路中的位置：

当前现象或学习者的问题 / 成功条件 / 为什么需要拆解这一处：

可复用的已有知识、作品或学习者自述 / 本步略过哪些基础讲解：

只需补充的 AI 工程差异 / 直接知识依赖是否存在实际缺口：

当前代码与材料位置 / 供应商能力和官方文档版本、日期：

## 从运行拆解机制

先展示的一个具体输入与完整运行 / 哪些是实测、合成或示意：

要观察的请求、工具、上下文、状态、媒体或结果字段：

本步的基本约束、待解释现象与可区分假设 / 拆解到哪里即可支持判断：

当前需要的图、读图入口与代码/数据对应；实际生成后再填写路径：

本步实现范围 / 是否不慎提前完成后续机制：

## 学习者参与和帮助程度

本步谁提出方案、谁选择变量、谁解释证据 / 学习者主导的一个实际决定：

首次示范、共同诊断或学习者主导，依据当前经验选择 / 下一次可减少哪种帮助：

AI 怎样修改和运行 / 修改前后对比什么 / 没有收益时怎样处理：

确需提问时的用途与已给依据；不把跳过基础变成逐项考试，不用连续填空追措辞：

出现歧义时怎样先澄清 / 卡住时怎样定位证据、补局部或给完整示范：

## 验证与边界

确已存在并核对的运行命令 / 正例、失败样例或边界场景：

最小成功条件与必要运行记录 / 结果、过程和模型自述怎样独立核对：

真实模型/合成测试分别证明什么 / 尚未验证的模型或外部服务能力：

版本、延迟、费用、检索或权限中本步真正需要观察的内容：

已有授权和实际工具条件 / 当前机制需要的边界：

## 收口与自然复访

原问题—机制—实际证据—剩余边界 / 哪项解释被修正：

由学习者决定或参与选择的下一处问题 / 后续任务中可自然复用的近变体：

跳过讲解、提示下判断、独立证据分别说明；没有独立证据也可继续。小步结束时只记录实际发生的观察，不把维护、示范或代码完成写成学习者掌握。
