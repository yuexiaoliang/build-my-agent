# AI 应用工程能力与验收

终点不是“会调用一个模型”或“会使用一个 Agent 框架”，而是：面对没有原样讲过的需求，能选择合适的 AI 架构，借助 AI 编码，建立验证与可观测性，诊断失败并交付可维护的应用。

Agent Harness 是重点技术纵深；毕业验收同时要求 RAG、AI UX、多模态/Realtime、Evals/Observability、生产后端和模型优化的主要能力。

## 四种证据分开

作品证据是代码版本、实际命令、运行轨迹与独立结果核验；学习证据是学习者实际判断、依据、帮助程度和适用范围；教学行为证据是导师实际处理反馈的过程；外部反馈是明确场景中的真实用户反馈。

材料已准备不等于实现完成；AI 编码或测试通过也不等于学习者掌握。允许开卷、运行、查官方文档和让 AI 写代码，关键判断与证据必须能被学习者解释。

## 核心能力

| 能力 | 有价值的证据 | 不足以证明 |
|---|---|---|
| 解释 | 沿输入定位模型、检索、工具、状态、媒体和后端链路 | 背术语或复述刚给的答案 |
| 设计 | 在完整方案出现前提出需求、约束、选项和验收 | 只会选择最大的模型或最复杂 Agent |
| 诊断 | 用 trace/eval/日志提出可区分假设并验证修复 | 随机改 prompt 到一次成功 |
| 评测 | 有任务集、grader、保留样例、重复试验和失败记录 | “试了几次感觉不错” |
| 优化 | 用同一 eval 比较质量、延迟、成本和复杂度 | 单独展示 token 下降或一次更快 |
| 安全 | 身份、数据、工具权限和审批由程序实施并有反例 | system prompt 里写“不要泄露” |
| 迁移 | 新需求里重新选择是否使用 RAG、Agent、Realtime 等 | 原项目换名字 |
| 交付 | 干净环境可启动、失败可定位、关键检查可复现 | 一段成功录像 |

## 阶段出口

**S1 LLM 应用基础与 AI UX：** 从零完成一个可观察的 AI 功能，能解释模型请求、结构化结果、流式状态和前后端边界。

**S2 RAG 与 Context Engineering：** 完成可测量的检索增强链路，能解释搜索、切分、重排、引用与上下文选择。

**S3 Agent Harness 与生态集成：** 在已有应用上构建受控 Harness，理解工具、循环、状态、工作流、MCP 与集成边界。

**S4 可靠执行与安全边界：** 让有副作用和长任务可控，覆盖校验、权限、隔离、取消、幂等与恢复。

**S5 多模态与 Realtime：** 交付至少一个图像/文档能力和一个实时音频交互，解释媒体链路、延迟与降级。

**S6 Evals 与 Observability：** 建立可重复评测与端到端 trace，用证据定位模型、检索、工具和系统问题。

**S7 模型选择与成本性能优化：** 能在质量、延迟、成本和复杂度之间做有数据依据的模型与系统优化。

**S8 生产交付与独立迁移：** 完成可部署的 AI Web 产品，并在陌生需求中独立选择架构、验证方案和迁移边界。

## 毕业证据包

主线毕业至少需要以下真实产物，它们可以来自一个持续演进的主项目，而不是八个互不相关 Demo：

1. 一个可运行的完整 AI Web 产品，包含真实的前后端和模型边界。
2. 一条经过 retrieval/answer eval 的 RAG 或搜索增强链路，并能说明何时不需要 RAG。
3. 一个自己逐步构建的 Harness，覆盖 tools、loop/state、预算/停止和至少一种生态集成；不能用预制参考程序代跑。
4. 一次多模态实践与一次 Realtime/低延迟交互，能诊断媒体、会话和 UI 状态。
5. 一套可重复 eval + regression + trace/metrics 证据，可用于定位模型、检索、工具和系统问题。
6. 一次模型/系统优化实验，比较质量、延迟、成本和复杂度。
7. 一次真实部署，处理 secret、认证/授权、数据隔离、配额/限流、后台任务和监控中实际需要的部分。
8. 一个陌生需求迁移与技术答辩，说明为什么使用或不使用某项 AI 技术，并列出未验证边界。

## 技术边界

课程覆盖 AI Application Engineering 的主要技术面，但不声称覆盖“所有 AI 技术”。模型预训练、CUDA、分布式训练、推理内核等属于模型工程/ML Systems 的另一条纵深；S7.4 只要求理解 fine-tuning、蒸馏和合成数据何时值得做、需要什么数据和评测，可按条件做小规模实验。

具体测试、场景和评分器在对应本地小步建立；评分器先用已知正反例校验。安全与权限要求优先使用可验证检查，不让 model grader 成为唯一裁判。
