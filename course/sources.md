# 导师按需查阅的来源入口

不是学习者的预读材料。本页保留官方入口供本地备课核对；本次骨架调整未重新逐页核验，也没有选择或验证某个具体 SDK、模型或 Node 版本。

- [Anthropic：Building effective agents](https://www.anthropic.com/engineering/building-effective-agents)：方案复杂性、工作流与 Agent 的架构讨论。
- [IES/WWC 教学指南](https://ies.ed.gov/ncee/wwc/PracticeGuide/1)：工作样例、图文与复访等教学设计依据。
- [Node.js TypeScript 文档](https://nodejs.org/api/typescript.html)：本地初始化时核对运行与类型检查的边界。
- [TypeScript 配置文档](https://www.typescriptlang.org/tsconfig/)：按当前实际工具链选择配置。
- [OpenAI API 文档](https://developers.openai.com/api/docs/)：仅当选择此服务时核对相应接口；并非课程限定提供商。
- [SVG 标准](https://www.w3.org/TR/SVG2/)与 [Mermaid CLI](https://github.com/mermaid-js/mermaid-cli)：本地需要制图时按实际工具选择。

事实核对以当前使用的接口、版本和原始材料为准；工程建议不是通用定义，教学原则不是学习效果保证。导师提取当前必要事实讲解，不把链接列表当作解释。
