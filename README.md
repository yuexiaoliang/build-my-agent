# Build My Agent

面向有编程基础、初次学习 AI Agent 的中文开发者。用 TypeScript 从零实现企业业务 Agent，学习如何把新需求转化为可验证、可维护的系统。

## 学习方式

学习阶段的代码由 AI 编写，每次只实现当前课程的一小部分。每章遵循“说明本步目标 → AI 增量实现 → 讲解代码差异与执行过程 → 运行观察 → 理解检查 → 复盘”的顺序。学习者重点理解为什么这样设计、代码如何运行、结果是否正确；不要求手敲代码、填 TODO 或脱离 AI 编程。

先由 AI 从基础代码逐步构建核心循环，再比较框架。AI 不提前实现后续章节功能，每步保留可运行成果、变更说明和验证证据；用户有理解疑问时先讲清当前步骤，再进入下一步。企业主线使用合成数据和本地业务系统；编程、浏览器操作、数据分析、多模态通过迁移实验覆盖。

“独立制作 Agent”指学习者能够定义需求、理解方案、指导 AI 实现并判断结果，代码始终可以由 AI 编写。理解检查以复述执行过程、观察运行结果和讨论一个条件变化为主，不以代码默写作为门槛。

模拟系统是提前准备好的教学基础设施，主线不要求学习者实现 CRM、ERP 或普通 CRUD。前几章只使用本地工具；接入企业 API 是一章明确的学习任务。

## 开源准备

文档以中文为主，术语附英文名；计划覆盖 Windows、macOS、Linux。教材引用固定源码版本，依赖在实现阶段锁定。当前公开内容为课程设计文档，尚未添加项目许可证；正式课程发布前完成代码与教材许可证选择、署名和贡献指南。
