# Build My Agent

**从 Agent Harness 的最小完整运行出发，按第一性原理逐层拆解，系统学习 AI Application Engineering。**

面向已有前端经验的学习者。先看一个任务怎样经过模型、工具、程序边界和状态到达结果，再围绕未知行为补充所需机制。熟悉的接口、异步、类型和状态管理直接复用，把精力放在新的 AI 工程问题上。

总目标是能借助 AI 独立设计、实现、诊断、评测、优化和交付 AI 应用。Harness 是入口和重点纵深；RAG、多模态、Realtime、评测、可观测性、安全、模型优化与生产交付都有正式学习落点。

## 开始或继续

在本地对授课 AI 说：

> 读取 AGENTS.md，按当前课程路线继续。先看一个最小 Harness 任务的完整运行，沿我不熟悉的环节拆解；熟悉的知识略过基础讲解，只准备当前小步。

课程入口是 catalog 的 `entryUnit`。已有本地代码可按当前任务复用，历史证据不作为旧课入口。续学按当前有效单元进行；用户授权的导航迁移不表示新单元已学习或完成。

入口只按当前小步建立一个受限、只读工具任务，观察请求、动作、工具结果和停止原因。后续核心系统不会提前生成。真实模型、合成事件和机制示意分开标注；没有实际调用时不宣称验证了模型能力。

## 怎样选择接下来学什么

课程按知识组和问题路径组织，编号用于稳定引用。知识依赖可以由已有经验满足，无需按编号逐一完成。

- 模型为什么这样回答：进入消息、上下文、输出契约和模型实验。
- 工具为什么重复、越权或无法停止：进入 Harness、授权、预算与恢复。
- 资料不足或引用失真：进入检索、上下文组装与数据生命周期。
- 效果、延迟或费用发生变化：进入评测、追踪和优化。
- 图片、文档或语音体验有问题：进入独立的多模态与 Realtime 实验。
- 准备让别人使用：进入产品试用、部署、监控与回退。

一个主产品可搭配少量专项实验。最小成功标准和运行记录从入口建立，各知识组完成时留下迁移或诊断证据。AI 可以编写代码，关键方案和证据判断逐渐由学习者主导。
