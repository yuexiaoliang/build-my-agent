# Build My Agent

**从前端出发，理解、构建并交付可靠的 AI 应用。**

Agent Harness 是技术深入方向；真实作品与经过核验的表达是长期积累。目标是增加职业选择，不承诺就业、流量或收入，也不预设你必须成为企业顾问。

## 开始第一课

在仓库中对授课 AI 说：**“读取 AGENTS.md，开始第一课。”** 不需要先读完路线、技能或参考资料。旧学习进度已清空，新的起点是 S1.1；实验台跑通不代表你已经学会。

需要查看当前位置：

```sh
npm run learn
```

## 先把一个小任务看完整

需要 Node.js **22.16.0 或更高**。本项目显式启用类型擦除；22.16.0 会出现实验性提示。运行不等于类型检查，两者单独验证。技术依据见 [来源](course/sources.md)。

```sh
npm start
```

打开终端打印的本机地址（默认 `http://127.0.0.1:4317`）。选择一个场景，观察**问题 → 模型请求 → 工具执行 → 结果回填 → 运行终态 → 独立样例检查**。

默认使用人为编排的合成响应，不联网、不需要密钥、不产生模型 API 费用。它演示的是程序控制机制，不是模型能力，也不是完整生产系统。网页不用前端框架和构建工具，便于从熟悉的界面直接追踪到 TypeScript 服务端。

命令行也可以运行：

```sh
npm run demo
npm run demo -- --scenario unsupported
npm run demo -- --max-turns 1
```

第二、三条是故障/边界实验，非零退出码是预期现象。所有运行保存到本机 `.runs/` 的独立目录，不覆盖历史、不自动提交。模拟脚本只针对内置固定任务；改问题不代表它理解了新任务。

## 开发与检查

```sh
npm ci --ignore-scripts
npm run verify
```

`verify` 包括 TypeScript 检查、离线程序测试与课程/资源一致性检查；不调用付费模型。首次安装开发依赖需要访问 npm；日常离线演示仅用 Node 内置模块。版本固定在 package-lock.json，不要求为了上课安装一批 AI 框架。

真实模型是可选实验，不是开课门槛：[环境与协议边界](lab/README.md)。默认禁用，密钥只在服务端，需显式启用并确认费用；已有适配器尚不等于已验证所有提供商。

## 学什么，交付什么

[课程路线](course/roadmap.md)以 `course/catalog.json` 为单一索引：

1. 做通一个可观察的 AI 功能，分清界面、程序和模型。
2. 亲自借助 AI 构建最小 Harness，理解契约、校验、回填和控制流。
3. 让执行可控，处理权限、预算、取消、记录与恢复。
4. 处理复杂上下文，并通过实验比较方案。
5. 完成可展示的 Web 产品与独立迁移，积累可核验的作品表达。

**当前交付边界：**第一阶段 4 个单元已备好教材、图片、场景和检查；后续阶段是具体设计规格，尚未标记为可开课或已实现。课程实际效果仍需真实试教。

## 目录分工

| 位置 | 职责 |
|---|---|
| `course/` | 能力路线、学习单元、实际图片与验收 |
| `lab/` | 已实现的受控实验台、参考实现、合成场景和检查器 |
| `harness/` | 学习者逐步构建的作品区，当前尚未开始 |
| `.agents/skills/` | 导师与教学配图技能；不会自动赋予工具能力 |
| `.learning/` | 从零开始的检查点；只记录实际观察到的学习证据 |
| `portfolio/` | 可选的作品与内容沉淀，不是日更或获客指标 |

本仓库没有替所有内容作新的许可证选择。正式开源复用或发布许可需要所有者另行决定；不要由 AI 擅自授予第三方权利。
