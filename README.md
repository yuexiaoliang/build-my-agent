# Build My Agent

**从前端出发，以 Agent Harness 深化 AI 应用工程能力。**

技术学习是主线；通过真实作品逐步形成可验证的工程能力，并按需沉淀专业表达。

## 在本地从零开始

把仓库放到本地工作目录，向授课 AI 说：

> 读取 AGENTS.md，开始第一课。请先准备当前小步，再带我逐步建立项目，不要一次生成完整系统。

本仓库是**课程设计与教学规则的起点**，不是已完成的教程项目。没有预制实验台、参考 Harness、具体课件、图片或练习答案；也没有可直接启动的应用。无需先找启动命令或安装一套预设依赖。

本地导师会从已有前端经验和当前目标出发，检查必要环境，准备当前小步的完整示范与必要图片，在课堂过程中由 AI 逐步编写、解释、运行代码和测试，随后记录实际学习证据。不是先搭完整系统再让你阅读，也不是让你手敲所有代码或填写 TODO。

**从零开始不等于没有备课。** 本地导师负责当前小步的讲解、图文、练习依据和补救方式；未开始的后续内容只保留目标与依赖，不提前实现。

## 现在准备什么，之后生成什么

| 现在的设计材料 | 在本地学习时逐步产生 |
|---|---|
| 五阶段路线、单元目标和验收要求 | 当前单元的讲义、示范、练习与反馈 |
| 导师与教学配图技能 | 与实际讲解及代码对应的图片 |
| 最小备课模板、证据记录规则 | 应用代码、测试、所需依赖与运行记录 |
| 空白的个人学习起点 | 实际发生的学习进度与判断证据 |

客户端能显示图片是已知条件。配图不限定 Mermaid，也不要求模型原生输出图片；本地导师使用实际可用的工具制作。技能不自动附带图片服务。

## 资料分工

- [路线说明](course/roadmap.md)：阶段关系；[课程索引](course/catalog.json)：单元目标、依赖和备课状态。
- [能力验收](course/assessment.md)：什么证据支持什么判断；[备课模板](course/templates/lesson.md)：仅供导师按需使用。
- `harness/`：空白作品起点，代码在本地学习中建立；`.learning/state.json`：唯一的当前学习位置。
- [作品表达](portfolio/README.md)：把已经验证的实践按需整理为可复用的专业表达。

不需要预读上述资料。导师只呈现当前必要部分；不会因为“继续”或测试通过就自动记录掌握。

项目初始化、Node/TypeScript 版本、模型接口和检查命令在本地当前小步需要时确定并记录。本骨架尚无运行时代码，因此不存在已经通过的运行测试、模型兼容性或教学效果验证。
