# 第 03 章汇总 · Agent Loop

- 日期：2026-09-15
- 本章核心问题：如何根据观察继续行动？
- 章末 tag：`ch03`；各步细节见 03.1–03.4 卡片

## 每一步给出的部分答案

- **03.1 工具结果回填**：模型无记忆 ⇒ 每轮都是独立请求；"继续行动" = 把历史装进下一轮 messages。回填三消息（user → assistant 含 tool_calls → tool 带 tool_call_id）；id 配对由服务端 400 强制；被拒绝的调用也要回填。
- **03.2 有界循环**：一步 = 一次模型请求；循环跑到没有 tool_calls（自然结束）或步数耗尽（不执行最后一轮、不续跑、如实报告、退出码 0）；轮数形状是模型行为，不是协议保证。
- **03.3 多工具请求**：一轮多请求合法且常见；`id` 决定配对、位置不参与判分（颠倒顺序仍 200 且模型对应正确）；`index` 是位置标号，流式分片才是它的主场（08 章）。
- **03.4 重复调用分级**：签名 + 连续计数；第 1 次正常 / 第 2 次加提示 / 第 3 次停止；提示不是强制，停止会有误伤（用户明确要求的重读也会命中）。

## 概念线

回填（03.1）让模型能"看见"观察结果 → 循环（03.2）把它变成"根据观察继续行动" → 多工具（03.3）扩大一次观察的吞吐 → 重复分级（03.4）给循环加上更早、更便宜的止损线。**循环的三种收场：自然结束、步数耗尽、连续重复停止——每种都有明确输出。**
