# 实验台：已有能力和未实现边界

## 当前可以运行

`npm start` 提供本机网页；`npm run demo` 跑同一个参考循环；`npm test` 覆盖协议、调度、记录和本地 HTTP。默认是 scripted：人为编排的合成响应，**不是真实模型、不是模型成功率评测**。每次创建独立 `.runs/<UUID>/`；`.runs` 不入 Git，不自动公开。

参考路径：`web/app.js → server.ts → reference.ts → providers.ts / tools.ts → check-result.ts → store.ts`。图片是课程静态示意。SSE 传输整轮事件，不是模型 token 流式解析。工具只有内存中的只读 `read_doc`；没有磁盘读写、命令执行、客户数据或多租户授权。

| 场景 | 要观察的行为 |
|---|---|
| normal | 读 testing、用同一 ID 回填、再回答 |
| unsupported | 产生回答，但未读取资料且命令错误，样例检查失败 |
| truncated | 截断时不执行工具，不当正常完成 |
| unexpected-tool | 未注册工具被拒绝，最终受限停止 |
| repeat | 同批超过只读重复基线，整批不执行 |
| malformed | 无效响应归为协议失败 |
| slow | 等待时可请求取消，或到达期限 |

样例检查器采用固定答案格式和来源记录；不同合理措辞也可能不匹配。结果叫 matched 而不是“模型正确率”。自定义问题不评分。它没有语义理解，不用于评价任意任务或学习者。

## 可选真实调用

先由维护者/导师核对提供商支持文本 Chat Completions、function tools 和 `max_completion_tokens`。将 `.env.example` 复制为 `.env`，自行填入模型与密钥并设置 `ALLOW_LIVE=1`。密钥绝不发到浏览器。启动后仍默认离线，网页每次选择 live 需确认；命令行需要显式选择：

```sh
npm run demo -- --mode live --max-turns 2
```

不默认重试。输出上限不是总费用上限；轮数上限也不是货币预算。输入受本课长度限制，但提供商计费、请求取消后的费用与服务端是否终止需另核对。先在控制台设置合适额度，再运行少量已知问题。

当前实现保留并校验 `finish_reason`；不接收未知停止值。只支持文本/函数工具的子集，不支持多模态、供应商专有推理回传字段或 token streaming。没有实际凭证调用的提供商兼容性必须标未验证，不能根据离线 transport 测试宣称可用。

## 取消、记录与安全

取消请求通过独立接口发送，UI 等 `run.finished`/result 才写确认；不能点击后直接宣布后台终止。AbortSignal 传给 fetch 和合成延迟，等待也有期限。不能强行终止无视 signal 的任意用户代码，不能据此声称物理副作用已回滚。

响应正文最多 256KiB，内部回答最多 16000 字符，单轮工具最多 8 项，整个模型轮数最多 8。最终轮不执行工具；同一只读请求超过两次整批停止是教学策略，不是所有产品的通用规则。

记录的是本程序规范化的消息、事件、终态和样例检查，不是原始 HTTP 字节录像，也不是可用于重执行副作用的恢复检查点。只有 result.json 写入成功才报告已保存；只存在 reservation.json 表示运行未完整保存。没有自动恢复或清理命令，以免误删证据。

服务只监听 127.0.0.1，检查 Host/Origin，拒绝未定义 API，密钥和 .env 不通过静态资源路由交付。这是本地单用户实验，不是认证授权齐全的生产服务；不要直接映射公网或放进多人共享网络。

## 环境复现

Node 22.16.0+，用显式 `--experimental-strip-types` 运行；TypeScript 检查另跑。维护检查使用固定的 TypeScript/@types 开发依赖。Windows/macOS 的实际验收与 Node 24 的 CI 结果分别记录，不从 Linux 一次通过推断。

如果端口冲突，在 .env 改 PORT；不自动杀掉未知进程。首次安装依赖失败先报告网络/版本问题，不改依赖版本冒充锁文件通过。测试临时文件均在系统临时目录，测试自身清理；真实运行记录永不自动覆盖。
