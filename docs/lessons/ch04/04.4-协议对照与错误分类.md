> **本步问题**：这套解析假设了 OpenAI chat.completions 形状；换成另一家的响应会发生什么？全章的错误该归成哪几类、各自由谁判定？

## 1. 目标与可观察任务

- 用一份 Anthropic Messages 形状的合成响应回放我们的 parser，观察它以哪种失败等级收场。
- 对照固定版本官方 SDK 的类型定义（只读对照，**不引入依赖**），列出我们的适配层没覆盖的协议维度。
- 产出课程通用的**错误分类总表**：类别 / 例子 / 判定者 / 退出码。本章四种失败形态各就各位。

## 2. 原理与执行轨迹

协议差异的真实例子（Anthropic Messages API，对照用）：

| 维度 | OpenAI chat.completions | Anthropic Messages |
|---|---|---|
| 助手内容 | `message.content` 字符串 | `content` 是 block 数组（`text` / `tool_use` 混排） |
| 工具请求 | `tool_calls[].function.arguments` 是 **JSON 字符串** | `tool_use` block 的 `input` 是 **对象** |
| 工具结果回填 | 独立 `role: "tool"` 消息 | `user` 消息里的 `tool_result` block |
| 用量 | `prompt_tokens` / `completion_tokens` | `input_tokens` / `output_tokens` |

三种失败等级（04.3 定义）在本步用作分析框架：这份"外星响应"进入我们的 parser，会是响亮失败、延迟失败，还是静默误解析？

蓝图边界说明：本章只做**手写适配 + 对照**，不实现流式解析（流式属第 08 章）；SDK 只用于对照类型定义，不进入依赖。

**预测题**：这份 Anthropic 形状的响应会是三种失败等级里的哪一种？一句话理由。

课堂共同完成的错误分类总表（课后回填实测）：

| 类别 | 例子 | 判定者 | 退出码 |
|---|---|---|---|
| 传输 / 服务端错误 | HTTP 401 / 400 / 500 | `ModelRequestError` | 3 |
| 响应结构损坏 | 非法 JSON、缺字段（04.3 定级） | `ModelResponseError` | 4 |
| 截断 | `finish_reason: "length"`（04.2） | ？（设计题结论） | ？ |
| 工具参数非法 | 未知工具 / 坏 JSON / 越界路径 | 02.3 闸门 | 6 |
| 执行失败 | 文件不存在等 | 执行器 | 5 |

失败路径：把"协议不同"误归类为"响应损坏"——报错会指错病根；分类表的意义就是让每类失败的判定者唯一。
