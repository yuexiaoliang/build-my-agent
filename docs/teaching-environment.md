# 教学环境约定 v0.2

状态：环境设计，尚未实现或验证。主线环境改为可重置的开发练习仓库，企业系统用于第 28 章迁移。

## 教学基础设施与主线的边界

课程维护者提前提供每阶段需要的稳定环境，学习者专注 Harness、工具适配与评测。练习仓库、演示站和业务 CRUD 不作为主线开发作业。基础设施可以先完成，Agent 功能仍按课程逐步增加。

每章绑定环境版本、初始代码与种子场景，提供启动、检查和重置方式。重置只作用于课程创建的工作区；不复用学习者日常仓库或真实账号。环境故障控制、参考补丁及隐藏测试不暴露给被评测 Agent。

## 开发者 Agent 主线环境

- 初期：合成文件与只读本地工具，不开放任意 Shell。
- 文件编辑阶段：独立练习目录、已知初始内容、补丁检查与状态核验；验证路径和符号链接边界。
- 命令执行阶段：预置容器或等效隔离环境，限制挂载、网络、凭证与资源；提供固定缺陷、测试命令和预期行为。不得将路径限制或 Git worktree 视为安全沙箱。
- 协作阶段：各任务独立工作区；worktree 用于修改隔离，执行安全仍依赖单独的沙箱边界。

基础篇默认不要求 Docker；执行隔离篇会引入容器或等效环境，按平台验证后确定工具。沙箱搭建原理可以单独解释，安装脚本和练习依赖由课程提供。

## 故障与评测

预置未知文件、错误工具参数、截断输出、模型超时、命令不退出、过量输出、取消、日志不完整、修改成功后响应丢失、工作区被外部修改、提示注入及协作冲突等场景。

离线固定响应用于测试协议与状态机，不能证明真实模型能力。真实任务记录模型配置、提示与工具版本、运行时版本、环境版本、用量和最终状态。日志不存放密钥，只记录接口实际返回且允许保存的内容，不假定可获取模型内部推理。

评分器在 Agent 工作区之外运行，核对需求、补丁、测试与环境状态。保留开发集和未用于调优的任务；标记随机性和基础设施故障，避免把环境失败误记为模型能力失败。重放事件默认不重新执行工具。

## 迁移环境

| 环境 | 提前提供的内容 | 学习重点 |
|---|---|---|
| 浏览器 | 本地演示站、固定初始状态、页面变化与异常开关 | 动态观察、DOM/截图、动作结果与 API 对照 |
| 资料与数据 | 带来源的固定文档、合成截图、只读数据库与验证答案 | 引用、检索、聚合核验和无唯一答案的评分 |
| 企业业务 | TypeScript HTTP 服务、SQLite、客户/订单/物流/政策/工单/审批种子 | 远程工具适配、身份、审批、幂等和审计 |

企业服务自行验证资源归属和业务规则，Agent 不持有审批人凭证；写成功但响应丢失可以注入并由独立检查接口核验。同一核心运行时接入所有环境，不复制整套 Agent。

## 发布门槛

逐项验证 Windows、macOS、Linux 的启动、场景加载和重置；记录平台及依赖版本，未测平台明确标注。隔离能力存在平台差异时说明具体限制，不声称完全等价。

环境默认绑定本机，使用合成数据和演示身份。公开部署前实现相应身份与隔离边界。每章提供最小接口说明及常见故障；确定性环境契约测试不依赖付费模型。当前所有发布检查均待实现后验证。
