# 制作路径：按本次图的需要读取

本页是维护者的操作参考，不是学习者作业。工具文档说明工具能做什么，不证明当前环境已配置。先核对实际工具及本机版本；只用当前可用和已授权的路径。这里没有新增自动渲染服务或通用命令包装器。

## A. 标准关系图：Mermaid

复用仓库现有 `scripts/render-diagrams.sh` 前先读取脚本。它提取讲义中的 Mermaid 块、输出编号 `.mmd`，再经 `npx mmdc` 生成 PNG。它需要 Bash、Mermaid CLI 与可执行 Chrome/Chromium；默认浏览器位置是 macOS 路径，其他平台要按实际可用浏览器设置 `PUPPETEER_EXECUTABLE_PATH`，不能声称全平台已验证。

运行示例仅适用于依赖已经配置的环境，目录中的编号是脚本命名，不是课程图的长期身份：

```bash
bash scripts/render-diagrams.sh \
  "docs/lessons/ch04/04.2-截断与finish_reason.md" \
  ".lesson-preview/ch04-04.2"
```

使用前确认本地包可用；`npx` 可能在包缺失时尝试下载，不让上课过程自动安装未知版本。直接使用已配置的 `mmdc` 时，官方命令形状为 `mmdc -i input.mmd -o output.png`（文件名是示例，要替换为真实源/输出）。记录实际命令与版本，不机械复制不存在的路径。

脚本会遍历输出目录已有的 `diagram-*.mmd`，删图后旧文件可能留下。优先用新的专用预览目录并核对本次块数；不要用旧 PNG 冒充本次生成，也不要为清理图误删其他工作文件。文件真正生成并核对后，才复制/提交到课程资源位置或通过附件交付。

Mermaid 可以表达多种关系和一些简单图表，但“能勉强排进去”不是采用理由。逐字段标注和精确内容布局改用 B，真实界面改用 D。

## B. 定制说明图：SVG / HTML / CSS

适用：原始 JSON—解析代码—内部对象的字段对应、局部放大、上下文窗口内容块、固定输入的前后对照。文本模型负责源代码，渲染器负责图片；并不需要自由生图模型。

SVG 适合形状、短文本和可控连线；代码块/较长文本用 HTML/CSS 排版。把课件内容当文本转义，不将未知仓库内容拼成脚本或可执行 HTML。字体使用环境中实际可用的中文字体，不分发字体文件；不要依赖外部 CDN、在线图片或网络字体来完成本地图。

可用路径是已配置的浏览器截图，或支持所需 SVG 特性的本地 SVG→PNG 转换器。先检查工具是否支持文本/字体/布局特性，不假定所有 SVG 渲染器输出相同。下面是 **Playwright API 用法片段**，需要宿主已提供实际 `page` 和已审阅的自包含 HTML；不是新增仓库命令：

```js
// 仅用于新建的本地课件渲染页面；不要对学习者已打开的页面使用。
// html 是已审阅且转义好数据的内容，不能包含外部资源或脚本。
await page.setViewportSize({ width: 1200, height: 900 });
await page.setContent(html, { waitUntil: "load" });
await page.evaluate(() => document.fonts.ready);
await page.locator("#figure").screenshot({ path: outputPath });
```

环境准备阶段创建隔离的新浏览器上下文；本地课件渲染禁用页面脚本并拦截非必要网络请求。需要 JS 的授权场景另行限定，不因“渲染”就执行来源未知的代码。确保 `#figure` 实际存在，截图不把边缘注释截掉；它是**生成的教学示意图**，不是运行中的 Agent 实测截图。

例如 04.2：左侧只展示当前关心的响应字段，中间是实际解析代码摘录，右侧是内部对象；同一字段同一标识，省略处明确标注。计划新增字段不能混进标为“当前代码”的那一侧。精确行号要绑定代码版本；不得写出一个实际文件中不存在的行号。

## C. 定量图：数据驱动绘图

适用：实验比较、延迟分布、成本、错误分类、误差范围。选择实际可用绘图库，例如 Matplotlib；读入已知数据文件并以代码生成 PNG。简单关系图不为此引入 Python，复杂统计也不因为已装 Mermaid 就强行压进其图类型。

画图前核对单位、样本数、成功率分母、聚合方法、缺失值和重复运行。如果显示区间，写明区间定义与计算依据；不从平均值凭空画误差条。没有数据不能生成带“实测”标签的趋势；合成数据仅能示范图形，并显著标明。

Matplotlib 的交付形状例如 `fig.savefig(output_path, dpi=180, bbox_inches="tight")`，随后关闭该图并实际检查产物。每个需要独立解释的图独立输出；样本、单位、来源不能被裁掉。图片与绘图代码及数据版本一并关联，重跑不等于数据仍然有效。

## D. 真实界面：截图与可追溯标注

先确认目标确实存在且有权访问。使用实际可用的浏览器/截图工具捕获已知页面或元素，记录页面/代码版本、动作与时间；不为了截图触发未授权的写操作。Playwright 的页面截图为 `page.screenshot(...)`，元素截图为 `page.locator(...).screenshot(...)`；调用前要有真实 page/locator，不能根据示例名字虚构现场。

保存原图和标注副本，裁剪应留下必要上下文；用精确标注工具加编号、框线和说明。原图可含私人信息时留在授权范围内，对外只交付脱敏副本；永久遮挡后检查导出图片与元数据，不仅靠可撤销的展示层覆盖。标注不能改变被观察到的文字、数值、按钮状态或时间顺序。

重建页面、模拟终端或 HTML 排版图必须叫示意，不能叫实际运行截图。没有图像输入能力的模型不能声称看到按钮位置或核验了标注坐标，应依据可用的真实观测或报告视觉核对缺失。既有图片的编辑必须先确认实际目标，遵从宿主图像编辑工具规则。

## E. 概念插画：可选，不是工程证据

适用：用户请求的类比/场景插画确实能帮助理解，且不会掩盖实际机制。使用宿主允许且已提供的图像生成工具，遵循其调用、编辑目标和结果交付规则；不能在 Skill 中假设一定有 `image_gen` 或某个收费接口。

没有此工具时，仍可用 A/B 表达抽象机制；只有确实必须用特定素材而又缺资源时报告缺口。不得擅自上传个人照片/轨迹到第三方，不能生成模型原本没有的“真实实验截图”，不让插画中的数值、代码和工程箭头成为未经核对的证据。

## 共同交付检查

PNG 是课程默认交付格式；SVG/HTML/代码可作为可维护图源保存。图源存在、PNG 已生成、图片引用可访问、视觉检查通过和学习者理解必须分别说明。只修改 `SKILL.md` 不会让所有渲染工具自动安装，也不能确保任意客户端加载 Skill 后自动发现图片。

正式图片回到相应课程资源目录或当前授权附件通道。嵌入图片时给简短替代文字和读图入口；暂时的本地预览路径不能当作永久资源地址。只有已经生成或确认存在的文件可引用，图源与产物版本不符时停止沿旧图验收。
