# 教学配图

已知客户端能显示图片。交付是**实际图片＋读图入口＋来源和检查状态**。不能因模型只输出文字而取消必要图示，也不能把绘图源码当图片。

## 先理解小任务

从导师已有上下文提取：要看懂什么、已教什么、同一任务的代码/数据/截图版本、展示范围、哪些答案要暂时保留。不要让学习者重复填表。普通局部定义无需凑图。

## 按目的选方式

标准流程/时序/状态可用 Mermaid；精确字段与代码对应用 SVG/HTML；统计图由实际数据绘制；实际界面用真实截图的标注副本；必要类比插画用当前实际可用的图像生成工具或有权使用的素材。插画不能冒充架构事实、实验数据或真实画面。

具体工具必须从当前工具声明或已配置环境核实。ChatGPT 的 image_gen、其他宿主技能或图片 API 不是本 Skill 自带能力，不把一个环境的工具名硬套到另一个环境。需要费用、外部上传或第三方素材授权时先处理；不假造图片 URL，不输出不存在的文件路径。

本课程已有 SVG 是可显示的图像文件，也保留可维护源内容。客户端需要 PNG 时按 `references/rendering.md` 转换；不要为了渲染改掉教学条件。已生成图片可供没有执行工具的导师复用，但先核对版本。

## 制作与检查

沿一个具体值或一条正常路径讲，必要时再加一个变化。图、代码和日志复用相同名字、字段与编号。图片不堆全架构，文字不塞成一堵方框墙。中文、连线、图注和正常显示宽度要可读；不只用颜色传递含义。

分别记录：内容是否与来源一致；文件是否实际生成；图片是否被目视检查；交付引用是否可用。模型不能看图时，视觉检查标未做，不用语法检查代替。实际渲染失败时说明具体故障并先用简短文本继续，配图仍待完成。

练习图片的高亮、图注、alt 和文件名都不能泄露保留答案。已经展示的推导属于有支持练习，不让配图成功自动变成学习者掌握。

输出回到当前讲义，不另建平行资料包。记录最少的来源、工具/版本、产物与检查状态，复杂制作细节放参考，不全部发给学习者。
