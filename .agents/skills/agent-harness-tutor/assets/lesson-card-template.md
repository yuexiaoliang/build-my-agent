# 短复习卡模板

小步结束保存到 `.learning/lessons/chNN/`，更新上一级 INDEX。卡片是个人证据摘要，不是第二份教材；详细过程引用讲义或 fixture。旧卡保留，新证据用注明日期的更正补充，不抹去原判断。

````markdown
# NN.M · 主题

- 日期与代码快照：
- 本步解决的问题：
- 一句话结论及边界：

## 先试着回想

一个关键问题/小变体（不把待研究的供应商未知行为当复习题）。

<details>
<summary>展开核对依据</summary>

简短解释；关键代码入口/讲义位置；必要时一条已登记的证据路径。

</details>

## 本次学习证据

状态：已讲解 / 有解释或预测证据 / 有迁移证据 / 待复核。
支持程度：独立 / 提示后 / 跟随示范 / 未观察。
具体判断及范围：
缺口与有效帮助：

## 下一步

当前阻塞项（无则写无）：
下一最小行动及原因：
复访触发点：下次恢复 / 再次使用该概念 / 阶段验收。
````

不虚构学习者自己的表述，不以“AI 已生成”标记掌握。短卡一般只保留一个最重要结论和一个边界，必要时扩展，不机械限制字数。

章末仍可保存 `chNN-汇总.md`：串起全章问题、概念依赖、剩余缺口与下一用途。质量信号记录题意/目标是否清楚、依据与提示、补救效果、隔课复用；预测命中只作原始现象，不汇总成能力分数。不复制全部卡片。
