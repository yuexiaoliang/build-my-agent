# 讲义模板：导师提前准备，课堂逐段使用

每小步一份，放在 `docs/lessons/chNN/`。开章前准备问题、依赖、示范和练习分支；未来接口/实验标明计划。学习者只需当前必要片段，不需要把所有预写讲义读完。

下列是备课字段，不要求对话逐项打印。示范要给完整解释，练习答案可以折叠，但不能把教学内容也藏掉。客户端已确认能显示图片，模型仅输出文本不是取消图示的理由；短定义不为形式凑图。

图片制作的单一规则来源是 [teaching-visuals](../../teaching-visuals/SKILL.md)。导师提供目标、前置、卡点、来源/版本和展示时机；按需要读取该 Skill 的制作参考。这里仅保留课堂组织与交付记录，不复制一套 Mermaid 专用规则。

````markdown
# NN.M · 用真实问题作标题

> 状态：已备课 / 已实现 / 已离线验证 / 已真实调用（逐项据实）
> 为什么学：当前任务会在哪里失败，本步解决哪一个判断。
> 本步目标：学习者能依据什么，解释/判断什么。
> 位置：上一机制 → 本步 → 下一用途；用已有任务地图突出本步。
> 前置：只列直接依赖；缺失时在本页补，不默认发阅读包。
> 阅读范围：当前只需第几节/哪张图；其他部分供回查。

## 1. 先看一个完整例子

具体输入 → 关键状态 → 代码入口 → 结果，逐步解释原因。
明确它是示意、静态走读还是实际运行。给一个“缺少该机制”的对照。

### 配图与带读（本步需要时）

- 给配图 Skill：目标与卡点、已教前置、实际代码/数据/截图及版本、本次显示范围、不能提前暴露的答案。
- 图片与边界：实际图片生成/定位后再嵌入，不能用图源代码替代图片；标明静态机制、计划设计、合成示意或实测。
- 读图入口：说明为什么看、从哪里开始、编号/箭头代表什么。
- 带读：先沿一条正常路径，再加一个变化；连接同一例子的图片、字段、代码和输出。复杂字段图、统计图、真实截图不强制使用 Mermaid。
- 交付状态：复用配图 Skill 的检查记录；只有源代码没有图片时仍标未交付，不把工具缺失说成客户端不能显示图片。

默认先聚焦一张主图和附近解释。前后对照依次讲，完整字段表可折叠；不支持折叠时由导师控制呈现范围。图不是另一份阅读作业，不只是把长段文字塞进方框。

## 2. 现在换你判断一个小变化

- 为什么问/用途：本题对应的工程判断。
- 类型：机制推导 / 经验实验 / 设计取舍。
- 已知条件与依据：当前实际交付的代码、图片、字段、需求、预算、权限；先补未教前置。
- 问题：一次一个具体判断。按编号、字段或动作定位，不只用颜色/坐标，不要求背图或重画整图。
- 回答范围：例如结论加一处依据；不是猜导师想法。
- 支持：先定位观测点，再给最小对照，仍卡住则完整示范。
- 反馈：哪些依据成立；错在何处；什么时候换例子或补前置。图或文字已展示的结论不算独立迁移证据。
- 可答性检查：当前交付的图文是否提供必要条件？示范图不冒充独立测验；练习图、图注、替代说明和命名均不能意外泄露保留答案。图片故障时先补临时说明，不将材料缺失判为理解失败。

<details>
<summary>练习后对照：参考解释与成立条件</summary>

给依据、允许的其他合理答案、证据边界。不把设计偏好写成唯一答案。客户端不能折叠时，练习阶段不同时发送此段，学习者要求答案时照给。

</details>

## 3. 实现与验证（按本步需要）

AI 增量修改的范围、入口与关键差异；不提前实现后续机制。
已有命令、计划命令分开；计划命令不要当成可执行指令发送。
已有 fixture 用完整真实路径；新 fixture 创建后登记 INDEX。
分别写：解析回放能证明什么、完整运行能证明什么、还不能证明什么。

## 4. 收口与复访

本步结论及边界；回到图中变化的连接；一个变体及何时复访；下一步为何需要它。
讲义保持中性，个人证据进短复习卡，不重复长日志或为每张图另建文档。

## 5. 验证记录

实际命令/代码版本/关键输出/fixture/结果范围。
未运行写未运行；运行记录不自动成为学习者理解证据。

图片记录（复用配图 Skill 的结果，不另造清单文件）：
- 用途与证据类型；源文件/数据/截图及版本。
- 实际制作方式、工具版本、图片位置与引用。
- 内容 / 产物 / 视觉 / 交付检查：已做或未做及依据。
- 读图入口与必要图注；仍缺什么。

真实教学反馈单独记录。没有图像输入能力的模型不能声称目视检查；静态审查不证明图片实际显示或学习效果。
````

备课时先检查题目是否真的服务目标；不为了填满模板发明题目、失败实验或图片。短问答不套此模板，验证输出不能预写成已发生的事实。

图片制作的命令、依赖、资源命名、真实截图与示意区别、故障处理及工具参考，在配图 Skill 中按需查阅。既有图源保留原位，不要求为新 Skill 一次迁移全部旧教材；课程维护也不因此完成任何后续课程功能。
