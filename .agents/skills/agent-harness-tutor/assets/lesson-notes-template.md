# 讲义模板：导师提前准备，课堂逐段使用

每小步一份，放在 `docs/lessons/chNN/`。开章前准备问题、依赖、示范和练习分支；未来接口/实验标明计划。学习者只需当前必要片段，不需要把所有预写讲义读完。

下列是备课字段，不要求对话逐项打印。示范要给完整解释；练习答案可以折叠，但不能把教学内容也藏掉。涉及角色、时序、状态或边界的新机制，按 Skill 的图文协同要求准备图和邻近解释，不把图示当可有可无的装饰，也不为简单问题凑图。

````markdown
# NN.M · 用真实问题作标题

> 状态：已备课 / 已实现 / 已离线验证 / 已真实调用（逐项据实）
> 为什么学：当前任务会在哪里失败，本步解决哪一个判断。
> 本步目标：学习者能依据什么，解释/判断什么。
> 位置：上一机制 → 本步 → 下一用途；用已有任务地图突出本步。
> 前置：只列直接依赖；缺失时在本页补，不默认发阅读包。
> 阅读范围：当前只需第几节/哪张图；其他部分供回查。

## 1. 先看一个完整例子

具体输入 → 关键状态 → 代码入口 → 结果，逐步解释原因。
明确它是示意、静态走读还是实际运行。给一个“缺少该机制”的对照。

### 图和文字一起讲什么

- 图的用途：要看清哪一种关系或变化，选择结构/时序/状态/前后对照；排障必要时用真实局部截图或输出片段。
- 图示及边界：Mermaid 图源写在本节；标明当前实现、合成示意或未来计划，指出省略条件。课堂呈现渲染图，不让学习者读绘图语法。
- 读图入口：从哪里开始，沿哪个编号/箭头走；用一句话说明形状、连线含义。
- 邻近讲解：用具体输入沿图解释一条正常路径，再加一个变化；不把所有分支一次铺开。
- 落到实现：图中节点/字段 → 同一个例子的代码入口 → 相应输出或证据。命名、调用 ID 和字段值保持一致。

默认先聚焦一张主图；前后对照依次展示，完整字段表可折叠。图不是另一份阅读作业，不只是把一大段文字塞进方框。简单局部问题用短文字、字段表或代码即可，说明选择而不强制填图数。

## 2. 现在换你判断一个小变化

- 为什么问/用途：本题对应的工程判断。
- 类型：机制推导 / 经验实验 / 设计取舍。
- 已知条件与依据：代码片段、图中具体箭头/状态、字段、需求、预算、权限；先补未教前置。
- 问题：一次一个具体判断。可沿图定位，不要求背图或重画整图。
- 回答范围：例如结论加一处依据；不是猜导师想法。
- 支持：先定位观测点，再给最小对照，仍卡住则完整示范。
- 反馈：哪些依据成立；错在何处；什么时候换例子或补前置。图已展示的结论不算独立迁移证据。

## 3. 实现与验证（按本步需要）

AI 增量修改的范围、入口与关键差异；不提前实现后续机制。
已有命令、计划命令分开；计划命令不要当成可执行指令发送。
已有 fixture 用完整真实路径；新 fixture 创建后登记 INDEX。
分别写：解析回放能证明什么、完整运行能证明什么、还不能证明什么。

## 4. 收口与复访

本步结论及边界；回到图中变化的那个连接；一个变体及何时复访；下一步为何需要它。
讲义保持中性，个人证据进短复习卡，不重复长日志或为每张图另建文档。

## 5. 验证记录

实际命令/代码版本/关键输出/fixture/结果范围。
未运行写未运行；运行记录自动成为学习者理解证据是不成立的。
图示检查另列：静态语义/语法检查、实际渲染检查、课堂读图反馈分别记录；哪些未做就写未做。
````

备课时先检查题目是否真的服务目标；不为了填满模板发明题目或失败实验。短问答不套此模板。验证输出不能预写成已发生的事实。

## 图文审阅场景

- “图看不懂”：应解释角色、连线和阅读方向，只追踪一个具体值；不再发更多复杂图。
- 讲 Loop 或恢复但只有长文字：应补时序/状态图及代码对应，而不是只追加“必要时画图”。
- 客户端不能内联显示：使用已有预览或讲义显示位置，并在对话中继续带读；无渲染能力就明确说明并用文本轨迹兜底，不让安装工具阻断学习。
- 图已经包含练习答案：明确它是有支持的练习，独立迁移另用变体，不能把看图复述当掌握证明。
- 示意图被称为“实测”：纠正证据类型，不能虚构截图、输出或学习反馈。

显示检查关注中文是否可读、箭头是否清楚、图是否过大或拥挤，以及不依赖颜色也能区分角色和状态。现有预览命令为 `scripts/render-diagrams.sh`；无法使用时记录未验证，不因已有图源就宣布显示正常。
