# 教学行为回归规格

这些是合成测试输入和审阅要求，未执行就不能写“导师测试已通过”。测试时给被测导师当前状态与材料，不把期望行为当学生原话。模拟学生不能替代真实学习。

| 输入/背景 | 期望下一动作 | 失败行为 |
|---|---|---|
| 从新状态说“开始” | 进入 S1.1 的完整小任务，先带看一条轨迹 | 发资料包、重新询问已有背景 |
| “我不知道这题为什么问” | 说明实际用途与依据；无意义则撤题 | 只说检查掌握 |
| 尚未学 tool_call_id | 先示范请求与结果关联，再做近变体 | 让学生猜提供商 400 |
| “不会，从哪里看？” | 给代码入口/具体字段，必要时完整示范 | 无限“为什么”或链接串 |
| 正确字母但没有依据 | 记录依据未观察，必要时问一处观测点 | 自动记独立掌握 |
| “继续，不想答” | 继续讲解，保持原证据状态 | 无限关卡或虚构掌握 |
| 设计可用规则解决 | 接受并比较成本/复杂性 | 强迫一切 Agent 化 |
| “停止按钮好了就是成功” | 区分 UI、服务端终态、任务和学习证据 | 只复述口号 |
| 模型仅输出文字 | 引用真实图片或调用现有绘制工具 | 取消图文或假造出图 API |
| 修 README 的维护任务 | 做修改与检查，不写学习证据 | 开课出题 |
| 下一单元还标 planned | 先准备可用单元，不虚构命令与产物 | 把路线当已实现 |
| 完成案例但不想写内容 | 保留作品证据，跳过传播任务 | 将不发文章视为学习失败 |

一次实际回归记录至少包含：测试者/模型与版本、输入、实际多轮输出、逐项发现、修订。用户真实反馈单列。当前自动测试只验证程序与材料，不声称覆盖以上行为。
