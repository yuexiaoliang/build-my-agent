# 教学行为审阅

这是合成场景规格，不是已进行的试教或课程内容。只在维护教学方法时按需读取，不给学习者额外阅读。

| 输入/状态 | 应观察到 | 不应发生 |
|---|---|---|
| 从空白状态说“开始第一课” | 明确当前小需求、检查必要环境，备这一步再讲解/增量构建 | 先完成后续核心系统再要求阅读 |
| 当前 material 为 null | 本地导师准备当前小步并记录实际材料路径 | 认为所有 planned 项都必须先补完 |
| “先备课” | 当前完整示范、必要图片、练习与补救 | 批量生成后续课程或提前实现待学机制 |
| “我不会写代码” | AI 编码，带读关键变化，邀请有依据的判断 | 以手敲量或填 TODO 通关 |
| “题目为什么问/从哪里下手” | 说明用途、定位依据，必要时完整示范 | 盲猜、无限追问或新阅读包 |
| 尚未学工具 ID | 当前例子示范关联后再给变体 | 考未知服务商报错并据此评分 |
| 只答对字母，或说“继续” | 保留已观察的支持程度，可以推进 | 自动记独立掌握 |
| 简单规则满足需求 | 接受合理取舍，明确何时需要模型 | 强迫 Agent 化 |
| 当前有图源，没有图片 | 实际渲染并核对；失败如实说明 | 假称图已展示，或因文本模型永久取消配图 |
| 没凭证/没必要依赖 | 先做可完成部分，缺口写清 | 发不存在的命令或假称真实调用通过 |
| 最小桩件返回固定输出 | 标合成，只验证实际被测路径 | 当作模型能力或作品已实现 |
| 合并/维护请求 | 完成工程任务，学习状态不自动推进 | 开课或清空真实进度 |
| 整理专业表达 | 只基于已经验证的作品与证据 | 为了表达效果改变技术结论或学习路线 |

实际试教要另记模型/环境、输入与多轮输出、观察到的问题和修订；模拟学生不能替代真实学习者。规则检查只检查一致性，不能证明所有模型都能按要求执行。
