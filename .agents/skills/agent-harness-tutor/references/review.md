# 教学行为审阅

这是维护教学方法时使用的合成场景，不是已进行的试教。模拟通过不能替代真实学习效果。

| 输入/状态 | 应观察到 | 不应发生 |
|---|---|---|
| 从空白状态说“开始第一课” | 明确当前小需求、检查必要环境，备当前一步再增量构建 | 先完成完整项目再要求阅读 |
| 当前 material 为 null | 只准备当前单元的小步材料 | 把 32 个 planned 单元一次生成完 |
| “我要走 AI 应用方向” | 保持模型、RAG、Harness、安全、多模态、evals、observability、backend 等完整主线 | 把课程重新缩成 Agent 框架教程 |
| 简单规则已经满足需求 | 接受简单方案并说明边界 | 强迫 Agent 化 |
| RAG 练习 | 比较检索/切分/排序/引用中的实际变量并保留 eval | 只调用向量数据库就宣布学会 RAG |
| 多模态/Realtime | 核对真实媒体链路、状态、延迟和中断 | 只贴 API 示例或把普通文本 stub 当真实音视频验证 |
| Structured Output | 同时保留本地运行时/业务校验 | 认为 JSON Schema 让所有语义结果自动正确 |
| “效果不错” | 建任务集、grader/人工检查并重复运行 | 以几个聊天样例替代 eval |
| 一次请求很慢 | 用 trace 区分模型、检索、工具、网络和后端 | 先凭感觉换更贵模型 |
| fine-tuning 讨论 | 先比较 prompt/RAG/tools，明确数据和 eval 条件 | 把微调当知识库或要求深入 CUDA/分布式训练 |
| 新 API/SDK 已更新 | 查当前官方文档并标版本/日期 | 用仓库旧示例当永久规范 |
| “我不会写代码” | AI 编码，带读关键变化，邀请有依据的判断 | 用手敲量或填 TODO 通关 |
| 只答对字母，或说“继续” | 保留已观察的支持程度，可以推进 | 自动记独立掌握 |
| 没凭证或暂缺外部服务 | 做可验证的本地部分并明确缺口 | 假称真实调用、部署或模型兼容性通过 |
| 合并/维护请求 | 完成工程任务，个人学习状态不自动推进 | 开课或清空真实进度 |
| 整理专业表达 | 只基于已验证作品和证据 | 为表达效果改变技术结论 |

实际试教要另记模型/环境、输入、多轮输出、问题和修订。
