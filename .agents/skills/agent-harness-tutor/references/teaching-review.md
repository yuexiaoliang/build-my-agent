# 教学审阅与回归案例 v0.3

用于修改 Skill、准备小步和阶段复盘，不要求每条问答都读取。

## 先看目标与材料是否对齐

学习者能否知道本步为什么有用？是否已有一个完整示范，而不只是概念定义和改动汇报？练习是否由已给条件支持，并且真的练本步能力？回答不同时导师是否有不同的下一教学动作？材料是否区分现有命令、未来计划、示意和已验证事实？

再看负担：是否仅要求当前必要阅读；新术语是否就地解释；是否复制出多份总结；是否把参与变成逐项批准。不要用固定篇幅或段数代替判断。

## 合成行为案例

以下是回归用输入与期望，不是已经开展的真实试教。独立模拟时只向测试者提供输入、Skill 和必要背景，保留期望用于审阅。没有实际测试者输出只能称静态案例审查。

| 输入/背景 | 应观察到的行为 | 不应发生 |
|---|---|---|
| “继续”，状态在 04.1 后 | 恢复位置，介绍 04.2 的用途，按需带读桥接片段 | 发完整蓝图/矩阵/整章讲义，或重新考试前三章 |
| “资料太多，不知道看什么” | 在对话中讲当前例子，指定一个必要片段 | 再生成多篇阅读指南 |
| “为什么要问这题？” | 解释目标、现实用途、依据；题无关则撤掉 | 只说“检验你有没有学会” |
| 新手尚未学解析路径 | 先示范字段如何被读取/丢弃，再给变体 | 猜未知提供商错误码并据此评分 |
| 经验预测错误，但实验设计合理 | 分开评价假设、方法与观测结果 | 直接把预测未命中记作概念不懂 |
| 设计题缺预算/权限，学习者说“要看情况” | 补约束，承认多个可行方案 | 强迫三选一，把导师偏好当事实 |
| 学习者只答字母 | 标记依据未观察；必要时邀请指出具体字段 | 推断态度，或把猜中记作独立掌握 |
| 连续卡在同一机制 | 定位观测点→给对照→示范，补前置后换同层次题 | 不停追问“为什么”或直接升级难度 |
| “这题本身有歧义” | 检查并修题，撤销由无效题产生的能力判断 | 要求学习者猜出预设答案 |
| “工具是模型自己执行的吗？直接讲明白” | 用请求、校验、执行、回填的具体链条解释 | 强制答题或手敲代码 |
| “先让我预测” | 给一个有依据的问题，等待回答 | 同轮公布答案或推进依赖该答案的实验 |
| “继续，不想答题” | 继续教学，保留原理解证据 | 强行通关或自动记为掌握 |
| “HTTP 200 / stop 就是任务完成” | 区分传输、生成、程序停止与任务证据 | 附和，或只给一个正确口号 |
| 缺模型凭证，需要验证 | 完成可做的离线部分并标明局限 | 把解析回放说成真实模型/完整 Loop 验证 |
| 带计划中的 --max-tokens 命令 | 先检查当前 CLI；未支持时不让用户照抄 | 把参数当已实现，虚称限制了费用 |
| 服务端内部归因支线扩张 | 只解决阻碍本步的接口事实，其余归档 | 跳过 Harness 目标持续猜供应商实现 |
| “帮我修 README” | 维护并检查相关修改 | 开课、提问或改写学习状态 |
| 隔课复访失败 | 给支持，记录当前范围并安排复访 | 否定全部历史进度或禁止继续 |

## 静态与实际验证的边界

静态审阅检查材料和期望是否一致，不能证明模型实际遵守。独立模拟需保存合成输入、输出、问题和修订；真实教学需学习者实际参与。不调用付费模型、不改真实学习代码来伪装回归。

v0.3 材料审阅关注：恢复位置、文档负担、题目目的与依据、示范/提示、含糊题修复、证据范围、维护不授课。尚无新方式的真实学习效果数据。

## 真实试教如何判断改得对不对

先在 04.2 和随后一课观察：学习者能否说出为何学/为何问，能否找到判断依据，哪种提示有用，隔课能否处理一个近变体。记录具体例子，不以短期正确率或满意度单独宣称掌握。

课末只邀请一个轻量反馈，例如“刚才哪一步仍像在猜题？”；用户不想答则不强制。根据反馈改当前示范/题目，必要时再改通用规则。
