# 你的作品工作区

当前从零开始，没有继承旧代码，也没有预填 TODO 要你手敲。第一阶段先在实验台看懂一个完整任务；之后由 AI 根据你的判断逐步创建这里的实现与测试。

`lab/reference.ts` 是课程准备好的受控参考，并不是你的“已完成作品”。参考代码有预算、取消和记录等保护措施，不要求首课把每个细节学完。进入相应单元时拆开比较，明确哪些机制是你的代码负责、哪些只是实验台保护。

第二阶段逐步在本目录建立自己的模型接口、工具契约和执行循环；使用相同的输入输出契约与离线反例，保留可替换性。验收时必须运行你的实现，不能仍然运行 lab/reference 却宣布已经完成。

第三阶段前不接入任意本机文件写入或 Shell。新增副作用要先准备独立工作区、授权、取消边界与结果核验。不为“代码量少”删除必要保护。
