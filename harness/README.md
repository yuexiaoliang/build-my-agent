# 本地逐步构建的作品

这里现在只有说明，没有应用代码、参考 Harness 或手填 TODO。第一次本地学习从小需求和最小功能开始；AI 按课堂需要初始化项目、选择实际可用的 TypeScript 工具链，逐步编写并解释代码和测试。

前后端与后续 Harness 核心在同一作品中演进，不先使用预制 Web 实验台，也不在第二阶段把现成参考程序改名当作新成果。目录与依赖可按实际项目调整，不被尚不存在的接口约束。

每个新增机制都说明原问题、最小变化、关键代码与验证。必要的合成输入、临时桩件和保护环境就地准备，并明确它们没有实现/证明什么。接入文件写入、Shell 或外部业务动作前，先建立适当隔离与授权；学习从零不等于开放不受控动作。

当前不存在启动、构建或测试命令。导师创建并实际检查后，再把真实命令与版本写进本目录说明；不用虚构的命令作为作业。
