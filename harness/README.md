# 本地逐步构建的作品

当前保留一个最小“反馈摘要”功能：浏览器把输入发给本地服务端，服务端校验后调用一个明确标注的合成 provider。它验证应用边界和错误处理，不会发起远程模型请求，也不能证明模型质量、真实延迟或费用。

## 运行条件与命令

- Node.js 24+（本步实测：v24.18.0）
- 无第三方依赖；不需要模型密钥

```bash
cd harness
npm test
npm start
```

启动后打开 <http://localhost:3000>。

## 当前边界

- `public/index.html`：收集输入、调用自己的 API、展示状态；不接触模型密钥。
- `src/server.ts`：限制请求大小、校验输入、记录非敏感元数据，并调用 provider。
- `src/model-provider.ts`：当前只有确定性的合成实现；以后真实 provider 仍须留在服务端。

已有接口、校验与页面可按当前任务复用，不作为必须先学的课程。路线从 catalog 的 H0.1 进入：实际学习时，只为当前小步建立一个有界只读工具任务，再按问题拆解。现在尚未实现 Agent 循环，也没有隐藏参考实现。

一个主产品可配少量专项实验，RAG、多模态和 Realtime 不必全部加入这个摘要功能。后续只修改当前任务需要的部分；维护课程不会提前实现后续机制或改变本目录既有运行证据。
